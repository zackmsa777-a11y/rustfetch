# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

The `rustfetch` project team takes security seriously. If you discover a vulnerability or security-related defect, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email or private advisory to the project maintainers via GitHub Security Advisories at https://github.com/zackmsa777-a11y/rustfetch/security/advisories/new.
3. Provide a clear description of the vulnerability, affected versions, and reproduction steps or proof-of-concept.

We will review reports within 48 hours and work with you on a coordinated disclosure timeline and fix release.
